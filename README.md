One job title, thirty-one characters. The title is:

> "Iceberg Mover, Titanic Division"

Iceberg towing is a real industry — ships really do tow icebergs out of
shipping lanes — so it sounds like a genuine job you can picture someone
doing. Then "Titanic Division" lands in two words: the one iceberg job
in history everybody knows ended badly. A fragment, not a sentence;
it reads at a glance, pictures instantly (a tug boat, a berg, a very
nervous crew), and the joke is the job itself, not an explanation of it.

Three candidates were weighed before this one: "Professional Mourner
for Strangers' Funerals" (44 chars — a real job, hired mourners crying
for strangers, but the twist needs a beat to land), the pick above
(31 chars — the shortest real-job draft, the Titanic twist lands
immediately), and "Senior Apologizer to Angry Geese" (32 chars —
funny, but nobody hires an apologizer for geese, so it reads as
invented wordplay rather than a real job).

## How it works

`main.ts` writes exactly that one title — no newline, no extra words — to
`/output/entry.txt`. It refuses to write anything that is not a single
line of 1–60 characters, then reads the file back and proves it holds
exactly that. No network, no secrets, no dependencies — just Node.

```sh
node main.ts
```
